Welcome to WebWorld!

With WebWorld you can play 3D worlds created by WebWorld game writers.   You can also write your own 3D avatars and worlds in Javascript.  This website will help you with that.

Download the alpha WebWorld locally from [here](webworld.apk).  Or, use the beta version (probably older) from Google Play.

- Read the  [Guide](guide.md) to understand how to create, package and share avatars and worlds for WebWorld players to use.
- Use the  [Reference](reference.md) for details on the JavaScript objects provided to build and control avatars and worlds.

If you've had experience with programming in JavaScript, you should be ready.  If not, you'll want to learn more about it.  If you've had other programming classes then JavaScript shouldn't be too hard to understand, at least to a depth needed to write JavaScript for WebWorld.
  
A good quick tutorial on JavaScript can be found at [learn-js.org](https://www.learn-js.org/).   You should be able to read through the sections and do the exercises and teach yourself!

If you get stuck and need some help, you can email me at bj@gallantrealm.com.
